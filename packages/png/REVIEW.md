# Reviewing `@variance-authority/png`

## Contracts

- **One comparison, however the bytes arrive.** Written in
  [README](README.md#the-rest-of-the-api).
- **The mask and the counts describe one comparison.** Written in
  [README](README.md#the-two-policies); pinned by
  [`src/compare.test.ts`](src/compare.test.ts).
- **No pairing makes a page read as unchanged.** Written in
  [README](README.md#content-that-moved-is-aligned); pinned by
  [`src/align.test.ts`](src/align.test.ts).
- **Past one search the rows still pair.** Pinned by
  [`src/align.test.ts`](src/align.test.ts).
- **Widths that differ are padded white, top-left, with no `alignment`.**
  Written in [README](README.md#content-that-moved-is-aligned); pinned by
  [`src/align.test.ts`](src/align.test.ts).
- **`/difference` refuses what comparison pads.** Pinned by
  [`src/difference.test.ts`](src/difference.test.ts).
- **A foreign raster claims nothing it did not see.** Written in
  [README](README.md#png-bytes-this-project-did-not-paint); pinned by
  [`src/foreign.test.ts`](src/foreign.test.ts).
- **`imageSize` says nothing about bytes that are neither a PNG nor a WebP.**
  Pinned by [`src/header.test.ts`](src/header.test.ts).
