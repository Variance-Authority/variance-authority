`select` over a record behind the merge base leaves to the mainline every test only the mainline's commits since the record reach. A test still runs when `file` precision over the checkout's own change from the merge base selects it, and a package bump or a change to what the suite rests on counts only when the checkout made it. A test that imports a path the checkout deleted runs, though only the mainline added that import. Nothing is left on the mainline's own tip with nothing changed. A file the checkout put back to the text the record ran, after the mainline changed it, is read whole. `--at-distance` places each test it keeps by its hops from the checkout's own change, never from a nearer one only the mainline made. The answer names how many it left.
