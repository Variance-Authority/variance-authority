`ask symbol` answers a function or an arrow function declared inside another function's body, with the function that holds it, and an export no entry publishes beside a published namesake. It names every declaration of the name it does not write out, the one nearest `--from` first. `ask search` weighs each word of a description by how rare it is among what the description reached, so a name holding the rare words is no longer outranked by every doc that also says a common one. The source index format moves to version 34, and the next scan rebuilds it.
