`variance ask classify --query <words>`, and `docs_classify` over MCP, say which words of a request are, whole, a package, an entrypoint or an exported name the workspace publishes, each with its package's area and dependency layer on the code map. The words that name nothing are listed on one line. Without a code map the answer names `variance index` and classifies nothing.
