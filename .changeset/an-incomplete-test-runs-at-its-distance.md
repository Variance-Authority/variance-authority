A test recorded incomplete runs in the leg of its distance from the change. Running part of a suite over an edit records the edited text, and every test carried over the edited region from the earlier text is held incomplete. The change then enters none of them, and `--at-distance` and `VARIANCE_AUTHORITY_AT_DISTANCE` left them all to the open leg, `3-`, so a `0-2` leg skipped a test that imports the changed file directly. `distanceFromView` places such a test by the shortest import path it ran to a changed file whose edit was read, and the leg those hops fall in runs it; stderr counts them in that leg. A test with no such path, such as a file whose every case skipped and that loaded nothing changed, runs in the open leg as before. A placed one counts toward the furthest hop, so an entered test with no hop count can move from a closed leg to the next one.
