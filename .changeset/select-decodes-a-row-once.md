`variance select` decodes a path once per recording it reads. Finding a file's row searched the sorted path column and decoded every row it probed, and every search probes the same rows first, so one selection decoded the same few thousand rows forty-four thousand times. Whether a mock disowns a crossing now asks whether the test mocks the file before it reads which tests crossed the block, and a column read again in the run it read last no longer moves that run to the back of its cache. Over this repository's unit suite that halves the column reads, from 892 thousand to 436 thousand, and `variance select --suite unit` goes from 532 ms to 482 ms with the same output.
