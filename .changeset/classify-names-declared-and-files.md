`variance ask classify` names a word shaped as an identifier — `ModuleLoader`, `child_process`, `utf8` — that is no package, entrypoint or published export by where it is declared, exported or not, as `declared lib/internal/modules/esm/loader.js:110`, and by the tracked file whose name without its extension it is, as `file lib/child_process.js`. Ordinary source comes before tests, then the file more files import; three of each are shown and the rest counted, each in the package on the code map nearest above it, or in no package. A checkout with no manifest is no longer answered with the map alone. A plain lowercase word is never looked up so. The workspace tree gains `importers`, how many files import each of a list of paths, and `@variance-authority/sense` exports `filesNamed`, the tracked files named by a base name.
