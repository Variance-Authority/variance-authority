# Journal 0029 — The box before the finding

**Date:** 2026-08-26

The first live use of presentation sensing selected a broad homepage section
and read every reported relationship as a property of that section. Changing
the locator did not change the nested findings. The acquisition boundary had
moved; the structural owner had not.

The section contained a prose flow and an illustration. Inside the illustration
were a header, an ordered list and a footer, and the list contained five repeated
rows. The missing move was to map that hierarchy before interpreting any
finding. Prose and illustration belonged to the composition without becoming
alignment peers. Repetition collapse belonged to the nested list.

Three live navigation controls made the other side of the boundary measurable
at a 1440×1000 viewport. On `atlassian.com`, the brand control's vertical centre
was 36px while five menu controls shared 34px. On the public GitHub page for
`paper-design/agent-plugins`, the brand and global controls shared 36px. On
`paper.design`, the brand and navigation links shared 30.5px. The peers crossed
wrapper boxes in all three pages, so direct-child inference could not express
the question. An explicit alignment reading could. Its final paint kept the same
selection visible as one median axis and one deviation-labelled box per member,
without reading the page again.

Paper's homepage also supplied the positive composition control. The hero is a
text and action flow above a large product illustration. Treating the
illustration's internal panels as boxes preserves the page's structure;
attempting to align every descendant with the hero copy destroys the question.

The analyzer then gained structural owners on findings and paint instructions,
stable finding ids, a pure owner focus, and an explicit cross-wrapper alignment
reading. A Chromium run against the local `#agents` section produced a 40-node
report with six patterns, five findings and 189 paint instructions. Seven live
acquisitions took 67.95, 69.76, 73.02, 76.63, 101.60, 157.27 and 889.71ms, for a
76.63ms median. One thousand owner-focus projections over the retained report
took 8.07ms total, or 0.0081ms each. Isolating the first finding reduced the
paint set from 189 instructions to one.

A separate five-record incident queue retained 251 characters and 27 elements
while a presentation-only edit separated the repeated records. Eight
relationship findings became zero. The result supports an edit loop without
turning fewer findings into a claim about information quality: the content
identity is the independent proof.
