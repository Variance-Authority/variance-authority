Selection reads the text a recording was cut from through the native addon, the same reader the journeys walk uses. When git cannot read it — no remote serves a blob a partial clone lacks, the root is no checkout, git 2.43 refuses a lazy fetch — selection fails with git's own reason, rather than reading every such file as missing and widening. A blob git holds as a git-LFS pointer is read as its content, or the read fails with git-lfs's reason.

The journeys walk reads a file unchanged since the recording from the checkout. When the checkout holds a git-LFS pointer there, the walk fails with the scan's message and the commands that fetch the content, rather than parsing the pointer as an empty module.
