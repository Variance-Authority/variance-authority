A region an edit beside it renumbered, such as the second of two callbacks after the first was deleted, is no longer read as one region lost and another gained. Siblings of the same name are paired by their cases first, and `caseMotion` returns the ones it paired this way as `renumbered`, which the motion text counts on a line of its own. Each test file's line now names the functions it entered and left, grouped by file, instead of a count of regions. `variance review --format markdown` draws the same motion as a Mermaid diagram, from test files to directories, above the folded text. `variance review --from-run <run id or URL>` downloads the `variance-review` artifact with `gh run download` and prints the review the run made.
