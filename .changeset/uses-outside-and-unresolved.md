`ask uses` names the files whose imports the source index resolved to no file when one could take the name, since a use there is not listed. For a name no file here declares but a file imports from an installed package or a runtime module, the answer names each source and the `discover --imports <source>#<name>` question that lists the files. `@variance-authority/sense` publishes `outsideSourcesOf`, and `importersOf` carries `unresolved`. `@variance-authority/mcp/tools` publishes `conjoined`, which joins words as `a, b and c`.
