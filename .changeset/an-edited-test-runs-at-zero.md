A test file the change edits is selected by its own source at zero hops, whether or not its record declared that source as a precondition or saw the test whole. Before, such a test was selected only through a precondition row naming its own file, so one recorded without it was skipped when whole and left for the open leg under `--at-distance` when not. A test seen whole that declared the text the change arrives at already ran it and stays skipped; a test the record did not see whole runs when its own file holds that text. `variance select` and `variance run --since` print a `read <file>:` line for every changed file, and `--format json` gives every changed file a reading under `readings`: what the reader made of it, or why no reader was asked of it — the record and the file graph hold nothing about it (`nothing`), it was recorded from a text nobody kept (`stale`), a suite declining relations did not measure it (`declined`), the suite's `ignore` matches it (`ignored`), or its rows, preconditions or importers answered for it (`answered`). Before, the first four were named only in a note that lists three, and the last nowhere. The notes now count each kind and say its remedy, and leave the names to the `read` lines.
