`variance covering` answers in text a page at a time. A whole file names each test file whose cases called into it once, the most cases first, with its case count, instead of listing every range with every case under it. The ranges no case called into are one line per state; a range is named only when it has something else of its own to say, such as a region on it no case entered. A line or a function keeps its file rows, nearest first. Either shows ten test files and three cases under each, counts the rest, and says the `--offset` of the next page; `--limit` and `--offset` page it as they page every `ask` listing. On a module 40 test files enter, the whole-file answer fell from 544 KB to 9 KB. `--format json` and `--format refs` are unchanged and name every case.
