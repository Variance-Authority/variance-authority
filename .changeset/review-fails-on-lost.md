`variance review --fail-on-lost` exits `1` when a suite no longer runs regions its base ran, so a project can require that a pull request keeps running what its mainline ran. It reads the comparison `--coverage` prints; a suite with no base is said on stderr and does not fail. A file the suite stopped loading counts when the checkout still holds it and the mainline ran it, which `SuiteChange.departed.ran` names.
