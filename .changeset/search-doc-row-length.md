`ask search` weighs a word a doc holds at most two thirds as much as the same word in a name, however short the doc. A row's weight is multiplied by how much of the question it holds, each word by its rarity, so a long doc holding every word of a question can sort before a short doc or a short name holding most of them, and a word most rows hold adds little. A name with more than one row — published by more than one package or exported from more than one file, or published and also exported — is weighed through one of them, by the words its name and that row's doc hold and by that doc's length, and shown with that row: the row whose doc adds the most different words of the question to those its name holds, then, of rows adding as many, the shorter doc, then the order the name's rows are shown in. A name no doc adds a word to is weighed by its name alone and shown with its first row in that order, whose doc orders it among names weighing as much by how near it writes the question's words. That order is the one the published section lists a name's rows in and the exported section picks the row it shows by, so every section shows a name through the same row: a published row before an exported one; a published row more files of the area import first and then the one with more import sites there, when asked with `from` or `to`, then the one more packages import, then the one with more import sites; an exported row from a source file before a test, a test before a story; then the doc's text, a row with no doc last, then the row's file and a published row's specifier, each in code-unit order. The published and exported sections used to settle a tie between rows of one name by where the index wrote them, which follows package and file names, so renaming a package or a file could change the row they showed; they now settle it by the doc's text and the row's path. Asked with `from` or `to`, a name is counted, weighed and ordered only through the rows of the area, the rows the section shows there: a published row a file of the area imports, or an exported row of a file in the area.
