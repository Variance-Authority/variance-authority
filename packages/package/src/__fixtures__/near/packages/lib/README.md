# lib

A package whose README is the only place some of its names are explained.

## Frame

A `Frame` is one captured moment: an offset, and nothing else. The declaration
says none of this, which is the point of the fixture.

## Silent

Nothing anywhere says what `Silent` is — not this section heading, which is
here so the file has more than one, and not the declaration.

## Deeply

`Deeply` is named here as well as in the README beside the file that declares
it, so the nearer of the two is the one that must win.
