A test recorded incomplete runs in the leg of its distance from the change. Running part of a suite over an edit records the edited text, and every test carried over the edited region from the earlier text is held incomplete. The change then enters none of them, and `--at-distance` and `VARIANCE_AUTHORITY_AT_DISTANCE` left them all to the leg that reaches the end, so a `0-2` leg skipped a test that imports the changed file directly. `distanceFromView` places such a test by the shortest import path it ran to a changed file it loaded, and the leg those hops fall in runs it; stderr counts them in that leg. A test with no such path, such as a file whose every case skipped and that loaded nothing changed, runs in the leg that reaches the end.
