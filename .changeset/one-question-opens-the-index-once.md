One question opens the source index once. `variance ask symbol` about a name
declared in many files read, checked and opened every segment of the index
again for each declaration it followed; it now does so once per answer, however
many readers the answer asks. On Kibana, `ask symbol --name mount` drops from
5.3 s to 2.9 s, and the same question to a warm help server from 4.1 s to 2.0 s.
