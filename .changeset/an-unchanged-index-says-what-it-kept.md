`variance index` says when it kept the code map and the questions because the index and the manifests did not move, as it already did for the journeys and the dependency lexicon: `questions: kept at <time>, because …`. Each keep is checked before the read it would spare: the code map against the index's manifest alone, before any segment of the index is read, and the questions against the head of the store they were published to, before the store is opened. `publishWorkspaceFromIndex` returns `{ generation, kept }`, where it returned the generation.
