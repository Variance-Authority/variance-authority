`variance covering` answers in text a page at a time. A whole file names each test file whose cases called into it once, the most cases first, with its case count, instead of listing every range with every case under it. The ranges no case called into are one line per state, the regions no case entered one sentence, each said once though a function opens on one range and closes on another; a range is named only when it has something else of its own to say. A line or a function keeps its file rows, nearest first. Either shows ten test files and three cases under each, counts the rest, and ends with the `--offset` of the next page; `--limit` and `--offset` page it as they page every `ask` listing. On a module 40 test files enter, the whole-file answer fell from 544 KB to 9 KB. `--format json` and `--format refs` are unchanged and name every case.

`@variance-authority/sense` exports `unenteredPlace`, the place a sentence about a region no case entered names it by: `the branch on line 6`.
