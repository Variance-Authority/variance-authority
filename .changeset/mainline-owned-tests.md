`select` over a record behind the merge base leaves to the mainline every test only the mainline's commits since the record reach. A test still runs when a reason that selected it names a file the checkout changed from the merge base, when imports reach it from one, when a precondition it declares loads one, or when it was selected through a file whose loads the scan could not all read. The answer names how many it left.
