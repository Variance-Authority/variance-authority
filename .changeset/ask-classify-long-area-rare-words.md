`variance ask classify` no longer discounts an area's words by its length. An area is long because it holds more files and names, so a source directory that declares many names, and alone holds a request's rarest words, now ranks above short test and fixture areas whose file names repeat its common words. On nodejs/node, `lib` ranks first for an ESM loader request and second for `child_process spawn exec`, where it ranked tenth and not at all.
