`variance view`'s History tab shows what surrounded each kept run: the highest load and resident memory any line of its cases ended at, and the machines the runs record the share kept with it names, with how many test files each ran. A run that kept none of them shows blanks. `machinesIn` is exported from `@variance-authority/sense`: `machinesBeside` of a runs record's text, as a share keeps it beside a record.
