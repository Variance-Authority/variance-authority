A module that loads through a function Node's `createRequire(import.meta.url)` made has that load read whatever the function is called: bound to a `const` of any name, or called where it is made. A literal specifier is an edge, so `ask discover` and test selection reach the loaded file, and a computed one is counted as a `require()` this cannot read. A function made for another file resolves from a place this cannot name, so its loads are counted the same way, even when it is named `require`.
