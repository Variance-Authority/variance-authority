`variance view` shows what surrounded a run. A case's Time by line lists each line's load average, resident memory, free memory and nodes added; the Cases table adds the highest load and resident memory each case's lines ended at; and where the runs record beside the record names machines, the Test files table names the machine each file ran on and the Overview lists the machines with how many test files each ran. Where a runs record is there and names none at the record's commit, the Overview says why. `machinesBeside` is exported from `@variance-authority/sense`: the machine each test file ran on, as the runs beside a record name it at its commit, or why none is named.
