A recorded run exits sooner after its last test: the end-of-run fold of a run's crossings, the case lay and the coverage record's encode run in the native addon, on every core and off the JavaScript thread. The record they write is byte for byte the one written before. On this repository's 14,000-test suite, the run exits 1.4 s after Vitest's `Duration`, down from 7.4 s.
