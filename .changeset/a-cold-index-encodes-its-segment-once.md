A cold index encodes its segment once, with its listing, rather than encoding it and then carrying the listing into a copy. A listing carried into a segment keeps the segment's column order, so the same segment carried twice is the same bytes. With `VARIANCE_AUTHORITY_INDEX_STAGES` set, `variance index --wait` also writes a stage line for each follow-up — readying, code map, journeys, dependency lexicon and questions — so the run's peak is named where it is set.
