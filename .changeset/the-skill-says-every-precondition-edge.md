The skill says every edge of reading case preconditions

The `variance-authority` skill's `case-preconditions` reference now says that
`--where` works with `--line`, `--function`, a whole file and `--since`; what
`Kept none … none said …` means; the `where` object and the `level` field under
`--format json`; that `preconditions: []` is *said nothing* and a missing field
is unmeasured; that a retry saying a different value is a contradiction; that a
`beforeEach` that throws records nothing; and that a case which never said an
axis name is read at the axis's base from the config, so `--where` at the base
keeps it. Its `covering` reference says that a `--line` outside every recorded
range is refused with exit `2`, which is not *no case ran it*.
