A test file the change edits is selected by its own source at zero hops, whether or not its record declared that source as a precondition or saw the test whole. Before, such a test was selected only through a precondition row naming its own file, so one recorded without it was skipped when whole and left for the open leg under `--at-distance` when not. A test seen whole that declared the text the change arrives at already ran it and stays skipped; a test the record did not see whole runs when its own file holds that text. `variance select` and `variance run --since` print a `read <file>:` line for every changed file: its reading, or why it has none. A file the record and the file graph hold nothing about reads `unread`, one recorded from a text nobody kept reads `stale`, one a suite declining relations did not measure reads `declined`, one the suite's `ignore` matches reads `ignored`, and one no parser was asked about reads `unasked`, because its rows, preconditions or importers answer for it. Before, the first four were named only in a note that lists three. `--format json` lists the unasked files under `unasked`, beside `readings`.
