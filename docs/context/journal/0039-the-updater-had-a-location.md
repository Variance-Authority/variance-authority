# Journal 0039 — The updater had a location

**Date:** 2026-09-03

The testing-surface view could say that a test addressed `DrawingPanel` and that
source files executed, while the commit tap could say that `DrawingPanel`,
`Canvas`, and `Clock` rendered. It could not say which live instance initiated
the commit. `PerformedWork` was the wrong evidence for that question: collateral
rendering is work, not an update origin.

Chippy supplied the useful precedent. Its React probe reads the renderer root's
`memoizedUpdaters`, and its inspection tools treat Fiber traversal as a reusable
diagnostic capability. The mechanism transferred; its topology did not. Variance
Authority already had a pre-navigation Eyes agent, authored AAA chronology, an
ephemeral Vantage watcher, retained runner artifacts, and an MCP connection. A
fixed-port helper, page registry, browser extension, active in-page callbacks,
and event replay would have duplicated ownership the product already assigns.

The first direct join used component names and was refused before it reached the
surface. A display name is not an instance coordinate, and two branches can
render the same component. The retained updater therefore became an
innermost-first structural path of name, key, and props digest, with its JSX
coordinate when present. Alternate Fibers are resolved while the commit is live;
no Fiber crosses into the Eyes archive.

That path changed the testing-surface answer. Each authored phase can report
update initiators whose structural path overlaps a DOM target the test addressed,
and initiators outside it, beside rather than instead of whole-test source
crossings. The three readings stay unequal: rendering is not initiation,
initiation is not source causation, and execution without attention remains a
replay candidate rather than a safe mock.

The traversal helpers fell out of the same work. Subtree reads stop at the given
root, parent reads follow `return`, source lookup climbs only enclosing composite
frames, cycles are tolerated, and every read is bounded. They expose the useful
part of a Fiber inspector without giving the package a page connection, a live
object registry, or authority to mutate the application.
