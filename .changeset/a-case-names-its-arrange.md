The skill reads what the covering cases arranged

The `variance-authority` skill has a `case-preconditions` reference: which
tests ran a function with sale prices mocked, what the tests covering a function
arranged, a case's flag-off twin, how a test helper declares what it arranged,
and what to do when `--where` answers unmeasured. The skill's config
table and its `covering` reference say that `covering` reads `names` from the
root `variance.config.json`. The `@variance-authority/sense` and
`@variance-authority/cli` READMEs link to the public case preconditions page.
