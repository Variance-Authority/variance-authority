# Spec 0003 — Command-line interface

**Status:** `built` — see [the status vocabulary](README.md#status-vocabulary)
**Package:** new — `@variance-authority/cli`

## Purpose

Make the system runnable from a terminal, a pre-commit hook, or a CI job without
writing test files that call the packages directly.

## Contract

```
variance run     [--config <path>] [--profile jsdom|chromium] [--subjects <glob>] [--intent <text>]
variance report  [--config <path>] [--format text|json] [--subject <id>]
variance accept  [--config <path>] <subject>... | --all
variance serve   [--config <path>]              # MCP over stdio
variance doctor  [--config <path>]
variance comment [--config <path>] [--body-file <path>] [--run-url <url>] | --marker
```

- `run` collects, decides, and writes a run report. Renders only what the cheaper
  tiers could not settle.
- `report` reads a written report. It never re-runs; the artifact is the contract,
  so a run can happen on a pinned machine and the questions be asked elsewhere.
- `accept` records that a change became the baseline.
- `serve` is the MCP surface, already implemented as a library.
- `doctor` reports what this machine can observe: browser present, fonts
  resolvable, renderer identity, and what a missing piece would cost.
- `comment` renders the docket as the body of a pull-request comment. It is the
  same binary the exit code comes from, so the comment on a pull request and the
  output of `report` cannot describe one run differently ([0005](0005-ci-integration.md)).

**This block was four things wrong until 2026-08-03, and the shape of the error
is the point.** It omitted `comment` entirely; it omitted `--config`, which every
command takes; and it wrote `accept <subject> [--all]`, a combination the parser
refuses. Each was written correctly and then overtaken — a spec is a call site
the compiler cannot see, which is
[ADR-0014](../context/adr/0014-examples-are-call-sites.md)'s argument arriving in
a document that argues rather than compiles. The synopsis above is now `USAGE`
verbatim and `tools/documentation.test.ts` fails if it stops being.

Configuration is a file the operator writes. Nothing is inferred from the
network, and nothing is downloaded at run time.

## Behaviour

**Exit codes are the interface for CI.** `0` nothing needs review, `1` changes
need review, `2` operator error (bad config, missing browser). A verdict and a
crash MUST NOT share a code.

**Every skip is stated.** A subject that was not observed reports why. Silence
about a subject is indistinguishable from a pass, and that is the failure the
whole system exists to avoid.

**`doctor` never guesses.** It reports what it observed, including that the font
probe reports metric-compatible substitutes as missing.

## Acceptance

1. **Met, by something stronger than what was written.** The criterion said
   `variance run` over the todomvc example must produce the verdicts the
   test-file path produces, with no test runner involved. That run never
   happened, and it is not the run worth having:
   [`cases/storybook-case`](../../cases/storybook-case) drives the whole CLI over
   an index `storybook build` wrote, which asks the same question — *does the
   binary reach the verdicts the library reaches* — against subjects this project
   did not author. Recorded rather than edited away, because a criterion replaced
   by a better one is a decision and a criterion quietly deleted is a hole.
2. **Met.** Exit 1 on a change and 0 on a no-op are
   `packages/cli/src/exit.test.ts`. Exit 2 with no browser under
   `--profile chromium` was argued in a comment on `rendererFor` and asserted by
   nothing until 2026-08-03; `bin.test.ts`, "opening a renderer", now holds it.
   It could not be reached through `main` on a machine that has a browser, which
   is why the opener is a seam rather than a lazy import inside a `try`.
3. **Met.** `packages/cli/src/commands/report.test.ts` — "round-trips through the
   run report contract unchanged".
4. **Met.** `packages/cli/src/bin.test.ts` — "lists every subject that was not
   observed, with its reason" — and `run.test.ts` for the exclusions reaching the
   report at all.

## Out of scope

- Watch mode.
- Interactive approval UI. `accept` takes a subject id.
- Anything that requires a backend to reach a verdict.
