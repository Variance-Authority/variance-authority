`ask search` weighs a word a doc holds at most two thirds as much as the same word in a name, however short the doc. A row's weight is multiplied by how much of the question it holds, each word by its rarity, so a long doc holding every word of a question can sort before a short doc or a short name holding most of them, and a word most rows hold adds little. A name with more than one row — published by more than one package or exported from more than one file, or published and also exported — is weighed through one of them, by the words its name and that row's doc hold and by that doc's length, and shown with that row: the row whose doc adds the most different words of the question to those its name holds, then, of rows adding as many, the shorter doc, then the order the name's rows are shown in. A name no doc adds a word to is weighed by its name alone and shown with its first row in that order, whose doc orders it among names weighing as much by how near it writes the question's words. That order puts a published row before an exported one; a published row more packages import first, then the one with more import sites; an exported row from a source file before a test, a test before a story; then the doc's text, then the row's file and a published row's specifier, each in code-unit order. Asked with `from` or `to`, a name is counted, weighed and ordered only through the rows of the area, the rows the section shows there: a published row a file of the area imports, or an exported row of a file in the area. There, a published row more files of the area import comes first, then the one with more import sites there, so an import outside the area never changes which row a name is weighed and shown through.
