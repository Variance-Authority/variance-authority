`variance ask classify --query <words>`, and `docs_classify` over MCP, say which words of a request are, whole, a package on the code map, an entrypoint or an exported name the workspace publishes, each with its package's area and dependency layer. A private package that publishes nothing is still named. The words that name nothing are listed on one line. Without a code map the answer names `variance index` and classifies nothing; a map folded from an earlier source index says so.

`packageLayers` gives each package's `area`: the innermost area of the code map whose page lists it.
