`variance select` decodes a path once per recording it reads. Finding a file's row searched the sorted path column and decoded every row it probed, and every search probes the same rows first, so one selection decoded the same few thousand rows tens of thousands of times. Whether a mock disowns a crossing now asks whether the test mocks the file before it reads which tests crossed the block, and a column read again in the run it read last no longer moves that run to the back of its cache. On a recording of 200,000 modules and 2,000 test files, answering a diff of 100 scattered files takes 27 ms instead of 117 ms on an M4 Max, with the same answer.
