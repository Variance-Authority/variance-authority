`ask classify` ends with the source files the request names, each with up to eight functions and classes it declares, exported first, under a line saying they are the answer, or the answer to their own words when other words are left; an exported name is looked up for the files it names too; a word naming only tests or stories gives way to its declaring source file; under `--from` or `--to` only the files the start point reaches are named; a file with nothing to list gets a row saying why. The block reads the source index alone, so it holds in a checkout git cannot list. A word that names a file is no longer asked `orient --files`. `@variance-authority/sense` exports `declarationsOf`, what files declare read from the source index without a listing of the tree.
