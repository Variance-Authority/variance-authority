`ask classify` ends with the source files the request names, each with up to eight functions and classes it declares, exported first, under a line saying they are the answer; a file with nothing to list gets a row saying why. The block reads the source index alone, so it holds in a checkout git cannot list. A word that names a file is no longer asked `orient --files`. `@variance-authority/sense` exports `declarationsOf`, what files declare read from the source index without a listing of the tree.
