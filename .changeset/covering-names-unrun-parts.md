`variance covering --function` names the parts of the function no case ran, a branch no case took or a nested function no case called, read the way the review and the handover read the parts they mark 🔴. The handover's last line suggests `variance covering --file <path>`, which runs, instead of a `--since` and `--file` pair the command refuses. The review counts both arms of a branch that share a line, a `} else {` or a one-line ternary, where it counted one.
