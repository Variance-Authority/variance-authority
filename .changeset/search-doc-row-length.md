`ask search` weighs a word a doc holds at most two thirds as much as the same word in a name, however short the doc. A row's weight is multiplied by how much of the question it holds, each word by its rarity, so a long doc holding every word of a question can sort before a short doc or a short name holding most of them, and a word most rows hold adds little. A name with more than one row — published by more than one package or exported from more than one file, or published and also exported — is weighed through one of them, by the words its name and that row's doc hold and by that doc's length, and shown with that row: the row whose doc adds the most different words of the question to those its name holds, then, of rows adding as many, the shorter doc, then a published row before an exported one, then the doc's text, then the row's file and a published row's specifier, each in code-unit order. A name no doc adds a word to is weighed by the doc of the row it is shown with. Asked with `from` or `to`, a name is counted, weighed and ordered only through the rows of the area, the rows the section shows there: a published row a file of the area imports, or an exported row of a file in the area. There, a name no doc adds a word to is shown with its published row the most files of the area import, then the most import sites there, else with its exported row there from a source file before a test or a story, then by the doc's text and path as above, so an import outside the area never changes it.
