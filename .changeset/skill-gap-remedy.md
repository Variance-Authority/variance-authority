The `variance-authority` skill says how to fill a gap an answer names: wire the producer it names, run the test file or case it names with the runner's own filter, for a source file the suite never loaded or is older than, run the test files `variance ask discover --to` finds importing it, or, in a suite that drives the code from another process, the specs that drive it — never the whole suite. For `undiffed` it says to fetch the base's commit. The testing skill now says what a story shows: the values each function was handed, a primitive as it is and an object as a ref and its kind, what a module's top level declared, and what the code printed.
